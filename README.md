# Titanic Survival Prediction 🚢

## Project Overview
This project aims to predict the survival of passengers aboard the Titanic using machine learning techniques and Python.

## Dataset
The dataset contains passenger information, including:
- Passenger class (Pclass)
- Sex
- Age
- Number of siblings or spouses (SibSp)
- Number of parents or children (Parch)
- Ticket fare (Fare)
- Port of embarkation (Embarked)
- Survival status (Survived)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Load the dataset.
2. Explore and analyze the data.
3. Clean missing values.
4. Perform exploratory data analysis.
5. Prepare the features.
6. Train a machine learning model.
7. Evaluate the predictions.

## Project Structure
- `README.md`: Project documentation.
- `titanic_survival_prediction.ipynb`: Python notebook containing the analysis and prediction model.

## Objective
The objective is to identify the main factors influencing passenger survival and build a model to predict survival outcomes.
